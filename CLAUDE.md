# ink

Agent skill for deploying and managing cloud services on [Ink](https://deployink.com) — a cloud platform for autonomous AI agents.

## Skills

- `/ink:ink` -- Deploy apps, manage services, templates, DNS, custom domains, and workspaces on Ink

Uses the [Ink CLI](https://github.com/mldotink/cli) (`npm install -g @mldotink/cli`). See `skills/ink/SKILL.md` for detailed instructions.
